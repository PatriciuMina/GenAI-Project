     Context

     The backend (PRs #1–#4) has JWT auth (POST /api/v1/auth/register|login, GET
     /api/v1/users/me)
     and GET /api/v1/organizations[/{id}]. There is no frontend yet. This task
     creates the React +
     TypeScript app with auth, role-based navigation, the Organizations
     list/details pages, placeholders
     for W2–W5, tests, and a dev guide for teammates without AI tools.

     Backend facts the frontend relies on (verified in code):
     - LoginResponse { accessToken, tokenType: "Bearer", expiresInSeconds } — no
       user info, so after
       login we call GET /users/me → UserResponse { id, email, fullName, role: 
       STUDENT|ADMIN, createdAt }.
     - JWT claims: sub (user id), email, role, exp (default 2 h, no refresh
       tokens).
     - RegisterRequest { email, password (8–72), fullName (≤150) }, always
       STUDENT; 409 on duplicate email.
     - Error body ApiError { timestamp, status, code, message, fieldErrors: 
       [{field, message}] };
       login failure = 401 "Invalid credentials"; validation = 400
       VALIDATION_FAILED with fieldErrors.
     - OrganizationResponse { id, name, description, contactEmail, createdAt };
       404 for unknown id.
     - No endpoint yet exposes the current user's organization memberships/roles
       (PRESIDENT/ORGANIZER/MEMBER).
     - Node 24.22 / npm 11 installed locally.

     Organizing, Node 24 LTS.
