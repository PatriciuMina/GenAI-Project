# Interview notes

Anonymised notes of user interviews for [`../06-ux-research.md`](../06-ux-research.md).

**Rules**
- One file per interview: `I-01.md`, `I-02.md`, … (same ID as in the interview log, 6.3).
- **No personal data:** no names, emails, phone numbers, student IDs, photos, or details that
  identify someone (e.g. "the president of <specific organization>"). Describe the participant
  by type only ("student, 3rd year", "organizer in a cultural organization").
- Only interviews done **with consent** (consent note in 06, section 6.1).
- Write what was said, not your interpretation. Interpretation goes into the findings (6.4).
- Commit the notes within 24 hours of the interview, via a PR like any other docs change.

## Template (copy into `I-NN.md`)

```markdown
# I-NN

| Field | Value |
|-------|-------|
| Date | YYYY-MM-DD |
| Participant type | e.g. student, 2nd year, member of one organization |
| Interviewer / note taker | team member names |
| Duration / mode | e.g. 25 min, in person |
| Consent given | yes |

## Notes per question
- **Q1 (<short question>):** …
- **Q2 …:** …

## Notable quotes (anonymised, verbatim)
- "…"

## Relevant to assumptions (A-NN from 06, 6.5)
- A-01: …
```
